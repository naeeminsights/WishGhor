# শুভেচ্ছা স্টুডিও

বাংলা শুভেচ্ছা কার্ড বানানোর ওয়েবসাইট: ৮টি উপলক্ষ, ৪৯টি নকশা, নিজের ছবি, স্টিকার, বাংলা ফন্ট, আর ফেসবুক পোস্ট, স্টোরি ও কভারের মাপে ডাউনলোড। কোনো সার্ভার বা ডাটাবেস লাগে না, তাই Vercel-এ একদম ফ্রিতে চলে।

## ফাইলগুলো
- `index.html` — হোম পেজ
- `birthday-card/`, `anniversary-card/`, `love-card/`, `new-job-congratulations/`, `exam-result-congratulations/`, `eid-mubarak-card/`, `pohela-boishakh-card/`, `wedding-card/` — প্রতিটা উপলক্ষের আলাদা পেজ (গুগলে আলাদা করে আসার জন্য)
- `assets/` — নকশার কোড (`app.js`), নকশা ও লেখার তথ্য (`data.js`), পেজের ডিজাইন (`style.css`)
- `og/` — ফেসবুক বা হোয়াটসঅ্যাপে লিংক শেয়ার করলে যে ছবি দেখায়
- `sitemap.xml`, `robots.txt` — গুগলের জন্য
- `vercel.json` — Vercel-এর সেটিংস

## ধাপ ১: GitHub-এ আপলোড
1. github.com-এ নতুন repository খুলুন (যেমন `shubheccha-studio`), Public রাখুন।
2. "uploading an existing file" লিংকে চাপুন।
3. এই ফোল্ডারের **ভেতরের সব ফাইল ও ফোল্ডার** টেনে ছেড়ে দিন (ফোল্ডারটা নিজে নয়), তারপর "Commit changes"।

## ধাপ ২: Vercel-এ ডেপ্লয়
1. vercel.com-এ GitHub দিয়ে লগইন করুন।
2. "Add New → Project" থেকে repository-টা Import করুন।
3. Framework Preset: **Other**। Build Command আর Output Directory খালি রাখুন। "Deploy" চাপুন।
4. এক মিনিটের মধ্যে একটা ঠিকানা পাবেন, যেমন `https://shubheccha-studio.vercel.app`।

## ধাপ ৩: নিজের ঠিকানা বসান (গুরুত্বপূর্ণ)
পেজগুলোতে এখন `https://YOUR-SITE.vercel.app` লেখা আছে। এটা আপনার আসল ঠিকানা দিয়ে বদলাতে হবে, নইলে গুগল ভুল ঠিকানা পাবে।
- কম্পিউটারে Node.js থাকলে: `node set-domain.js https://আপনার-ঠিকানা.vercel.app` চালান, তারপর বদলানো ফাইলগুলো GitHub-এ আবার আপলোড করুন। Vercel নিজে থেকেই নতুন সংস্করণ চালু করবে।
- Node.js না থাকলে: আপনার Vercel ঠিকানাটা Claude-কে দিন, ঠিকানা বসিয়ে নতুন ফাইল বানিয়ে দেবে।

## ধাপ ৪: গুগলে জমা দিন
1. search.google.com/search-console-এ যান, "URL prefix"-এ আপনার ঠিকানা দিন।
2. যাচাইয়ের জন্য "HTML tag" পদ্ধতি বেছে নিন, দেওয়া `<meta>` লাইনটা `index.html`-এর `<head>`-এ বসিয়ে আবার আপলোড করুন, তারপর Verify।
3. বাঁ পাশে "Sitemaps"-এ `sitemap.xml` লিখে Submit করুন।
4. "URL Inspection"-এ প্রতিটা পেজের ঠিকানা দিয়ে "Request Indexing" চাপুন।
5. একইভাবে bing.com/webmasters-এ যোগ করুন (Search Console থেকে এক ক্লিকে Import করা যায়)।

## গুগলে ওপরে আসতে যা করবেন
কেউ গ্যারান্টি দিতে পারে না যে প্রথম পাতায় আসবেই, তবে এগুলো সবচেয়ে বেশি কাজে দেয়:
- **উৎসবের আগে প্রচার:** ঈদ, পহেলা বৈশাখ, এসএসসি-এইচএসসির ফলের আগে ফেসবুক গ্রুপ ও পেজে নিজের বানানো কার্ড আর লিংক শেয়ার করুন। মানুষ ব্যবহার করলে গুগলও গুরুত্ব দেয়।
- **অন্য সাইটে লিংক:** ব্লগ, ফোরাম বা বন্ধুদের সাইটে আপনার পেজের লিংক থাকলে র‍্যাংক বাড়ে।
- **নিয়মিত নতুন কিছু:** নতুন উপলক্ষ (মা দিবস, পূজা, বিজয় দিবস) আর নতুন নকশা যোগ করলে সাইট "জীবন্ত" থাকে।
- **নিজের ডোমেইন:** `.com` বা `.com.bd` ডোমেইন কিনে Vercel-এ যোগ করলে বিশ্বাসযোগ্যতা বাড়ে। তখন আবার `set-domain.js` চালাবেন।
- ফল দেখতে সাধারণত কয়েক সপ্তাহ থেকে কয়েক মাস লাগে, ধৈর্য রাখুন।

## নতুন নকশা বা উপলক্ষ যোগ করতে
`assets/data.js` ফাইলে প্রতিটা উপলক্ষের `tpls` তালিকায় নতুন নকশা যোগ করা যায় (রঙ বদলে)। বড় পরিবর্তনের জন্য Claude-কে বলুন।
